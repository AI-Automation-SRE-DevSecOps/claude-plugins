# SRE chapter notes

One digest per chapter and appendix of Google's [*Site Reliability Engineering*](https://sre.google/sre-book/table-of-contents/) (`sre-book-*.md`) and [*The Site Reliability Workbook*](https://sre.google/workbook/table-of-contents/) (`workbook-*.md`). Each digest covers the chapter's principles, its exact numbers and tables, its recommended practices, the anti-patterns it warns against, and a few short quotes.

These notes are the source material for the `sre-engineering` plugin. They are not loaded by the skill; use them when you need more detail than its reference files give. Some formulas were images on the original pages; those notes flag them as reconstructed from the surrounding text.
